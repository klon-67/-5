# 🤖 Бойові роботи

**Бойові роботи** — це проста консольна гра на Python, де ти обираєш свого робота та б'єшся з випадковим ворогом.

## 🎮 Як грати

Спочатку обери одного з трьох роботів:

1. **STEEL** — 100 HP, 20 атаки
2. **TITAN** — 130 HP, 16 атаки
3. **PHANTOM** — 85 HP, 28 атаки

Після цього починається бій.

## ⚔️ Доступні дії

Під час бою можна вибрати:

- `1` — ⚔️ Атака
- `2` — 💥 Суперудар
- `3` — 🔧 Ремонт
- `4` — ⚡ Відновити енергію

## 👾 Вороги

У грі є кілька випадкових противників:

- SCRAP-X
- DESTROYER
- MEGA BOT
- DARK MACHINE

На початку кожного бою випадково вибирається один ворог.

## 🔥 Особливості

- 🤖 Вибір робота
- 👾 Випадкові вороги
- ❤️ Система здоров'я
- ⚡ Система енергії
- ⚔️ Звичайні атаки
- 💥 Суперудари
- 🔧 Ремонт робота
- 🔥 Критичні удари
- 🏆 Перемога або 💀 поразка

## 🐍 Встановлення

Для запуску потрібен **Python 3**.

Перевірити Python можна командою:

```bash
python --version
```

## ▶️ Запуск

Збережи код у файл:

```text
robots.py
```

Після цього запусти:

```bash
python robots.py
```

## 📦 Бібліотеки

Додаткові бібліотеки встановлювати **не потрібно**.

У грі використовується стандартна бібліотека Python:

```python
import random
```

## 🎯 Мета гри

Перемогти робота-супротивника, використовуючи атаки, суперудари, ремонт та енергію.

## 👨‍💻 Автор

Навчальний Python-проєкт **«Бойові роботи»**.
